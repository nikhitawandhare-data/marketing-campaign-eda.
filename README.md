# Marketing Campaign Performance & Customer Behaviour Analysis

## Project Overview

This project aims to analyse customer behaviour and marketing campaign performance using data analytics techniques.

The goal is to explore customer purchasing patterns, identify useful customer segments, and understand which marketing campaigns receive better responses.

## Project Objectives

- Understand customer demographics and purchasing behaviour.
- Analyse customer spending across different product categories.
- Evaluate marketing campaign acceptance.
- Identify patterns that can help improve marketing decisions.
- Present meaningful business insights from the data.

## Dataset

**Source:** Maven Analytics Data Playground
**Dataset:** Marketing Campaign Results

The dataset contains customer information, product spending, purchasing behaviour, and campaign responses.

Dataset source: [https://mavenanalytics.io/data-playground](https://mavenanalytics.io/data-playground)
